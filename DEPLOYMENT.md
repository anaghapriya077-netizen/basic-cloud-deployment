
# Basic Cloud Deployment

## Project Overview
This project is a simple static website created using HTML and CSS.

## Technologies Used
- HTML
- CSS
- GitHub
- GitHub Pages

## Deployment Platform
GitHub Pages was used to host and publish the static website.

## Deployment Steps

1. Created a public GitHub repository named basic-cloud-deployment.
2. Created an index.html file containing the website code.
3. Uploaded and committed the file to the main branch.
4. Opened repository Settings.
5. Navigated to Pages under Code and automation.
6. Selected Deploy from a branch.
7. Selected main as the branch and / (root) as the folder.
8. Clicked Save.
9. Waited for GitHub Pages to build and publish the website.
10. Opened the live website to verify deployment.
